# 🎮 Desafio 03 · XBOX•Dash: Inteligência de Vendas com Excel

Este projeto, integrante do Bootcamp **Santander - Excel com IA e Claude** desenvolvido em parceria com a [DIO](https://dio.me), apresenta o **XBOX•Dash**, um painel executivo de performance comercial projetado sob os critérios de minimalismo estrutural e tela limpa (Segoe UI).

## 🎯 Escopo Lógico & Tomada de Decisão (Perguntas de Negócio)

O dashboard foi estruturado para responder a três dores de retaguarda essenciais:
1.  **Faturamento por Categoria:** Qual segmento lidera as receitas (Consoles, Jogos ou Acessórios)?
2.  **Evolução Mensal:** Qual o comportamento da sazonalidade de vendas ao longo do ano?
3.  **Desempenho Regional:** Quais praças de mercado demandam maior alocação de estoque?

---

## 🛡️ Governança & Segurança de Processos

A ferramenta opera sob uma política rígida de segurança de dados:
*   **Aba APP:** Ocultação de linhas de grade e congelamento total de fórmulas via criptografia nativa do Excel, mantendo apenas os Segmentadores de Dados de Tempo e Categoria desbloqueados para interação do usuário.
*   **Aba apoio:** Protegida e ocultada na retaguarda para evitar dízimas flutuantes e manipulações indevidas na base sanitizada.
